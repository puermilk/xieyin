快速开始

选择媒体文件夹 → 抓取元数据 → 输出 NFO 与封面。不修改、移动、重命名原视频，不改动视频哈希。

对接飞牛影视

刮削元数据始终就地写入视频文件夹（NFO/封面）。开启对接后，额外推送一份到飞牛媒体库；未配置地址时自动跳过推送，不影响刮削。

番号刮削

扫描媒体文件夹，按番号抓取元数据。多源竞速（jav321 / javdb580），快源先写、慢源补字段；输出 NFO 与封面。

电影刮削

按文件夹名 / 关键词 / TMDB ID 抓取电影元数据（TMDB 网页源，直连）。

文件整理

清理媒体文件夹中的冗余文件。
整理会删除、移动、重命名文件，删除后不可恢复。检测到做种标记（@GROUP / *.torrent）的目录会自动跳过。
