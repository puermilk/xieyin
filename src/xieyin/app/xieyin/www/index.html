媒体目录 所有任务共用

番号刮削默认扫描此目录；电影刮削用它下面的 #recycle，也可以单独指定文件夹。

番号刮削 JavBus

文件夹名要能解析出番号，例如 ABC-123-UC、XYZ-456-UC。 已有同名 .nfo 的默认跳过；图片会写成同名 poster / fanart / thumb。

电影刮削 TMDB

没有番号的电影用这里。按文件夹名（或文件名）里的「片名 + 年份」去 TMDB 匹配，不需要番号。 命名如 Example.Movie.2025.1080p、[中文名].Example.Movie.2024、 中文名.2023 都能认。认不出来就填搜索词；还不行就填 TMDB ID （TMDB 页面地址 /movie/911430-f1 里的数字）。

清理共享 危险操作

规则：每个文件夹只保留最大的视频（>500MB），删除其余视频；nfo / 图片 / 字幕默认保留。 可选的「去域名前缀」只处理 489155.com@VNDS-2850-C.mp4 这种形式， 不会动 xxx@GROUP 这类 PT 发布名。

自动刮削 定时扫描 / qBittorrent

找出「有视频但缺 nfo」的文件夹自动刮；稳定期与 PT 保护避免误刮下载中的文件或做种目录。 qBittorrent 联动只刮「刚下载完成」的目录（已处理过的不会重复刮）。
